# SCOUTS Planet — Chrome-расширение v1.1

В этой версии оставлены **только два режима**: «Загрузка и отслеживание»
и «Стройка и расчёт». Старая многовкладочная панель удалена из автозапуска.
Файл `SCOUTS_Calculator_v6.js` хранится в репозитории как исторический код,
но расширение его **не выполняет**.

## Обновить уже установленное расширение

Удаление DevTools Snippet **не удаляет расширение** и не останавливает уже
выполненный JavaScript в открытой вкладке.

1. Открой `chrome://extensions`, найди старое «SCOUTS — планетарный калькулятор»
   и нажми «Удалить» (не очищай данные сайта SCOUTS).
2. Полностью закрой вкладки `scouts.su`.
3. Скачай [последнюю ZIP-ветку](https://github.com/granitniyivan2-projects/Calc/archive/refs/heads/scouts-live.zip), распакуй в постоянную папку.
4. В `chrome://extensions` включи «Режим разработчика» → «Загрузить распакованное расширение» и выбери именно папку `Calc-scouts-live/scouts`, где лежит `manifest.json`.
5. Открой игру заново. Справа снизу появится **«SCOUTS · Планета»** — только одна компактная кнопка. Нажми её для полноэкранных режимов. Крестик «Скрыть планету» вернёт к игре. Горячая клавиша: `Alt+Shift+P`.

## Как работают снимки

С расширением входящее событие `planetaryBase` читается в браузере, очищается
от не относящихся к планете полей и отправляется в наш интерфейс.
Открой планету в игре и дождись её загрузки. Обновление при следующем полном
событии происходит автоматически; когда игра не присылает его, можно повторно
открыть планету в самой игре.

- Геометрия планеты берётся из реальных гексов, искусственные карты не создаются.
- Данные остаются локально в браузере (`chrome.storage.local` и `localStorage`).
- Расчёт стройки виртуальный. Автозахват не отправляет команд в игру.
- Ручной импорт остаётся запасным способом.
- Код работает только на `https://scouts.su/*`.
- Перехват `WebSocket` через Proxy не гарантирует совместимости с будущими
  обновлениями игры и не исключает ограничения со стороны правил проекта.
- Предыдущий Snippet не нужен. Если он был запущен и страница не перезагружалась,
  его элементы могут оставаться в памяти до перезагрузки вкладки.

## Обновления в дальнейшем

Распакованное расширение Chrome **не обновляется само из GitHub**: после коммита
нужно заменить файлы в локальной папке, нажать «Обновить» у расширения
в `chrome://extensions` и перезагрузить страницу игры.
Установка расширения из архива производится вручную. Удалять и создавать
новое расширение при каждом изменении не требуется, если обновляешь ту же папку.
