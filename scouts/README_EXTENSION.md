# SCOUTS Planet — локальное расширение Chrome

Назначение: запуск калькулятора и **автоматическое считывание полного снимка** планеты (`planetaryBase`), который штатно приходит в браузер через игровой WebSocket. Расширение не отправляет запросы или команды в игру. Отслеживание работает **только при получении нового полного события**: для обновления открой/обнови планетарную базу в SCOUTS.

## Установка

1. Скачай ZIP ветки [`scouts-live`](https://github.com/granitniyivan2-projects/Calc/archive/refs/heads/scouts-live.zip) и распакуй.
2. Открой `chrome://extensions`, включи **Режим разработчика**, нажми **Загрузить распакованное расширение**.
3. Выбери папку `Calc-scouts-live/scouts` — **именно эту папку**, в ней лежит `manifest.json`.
4. Открой `https://scouts.su/` и войди в игру. Калькулятор запускается автоматически без Snippets.
5. В игровом разделе «Хранилища → Планетарные базы» открой планету. После получения `planetaryBase` данные попадут в режим **Загрузка и отслеживание**.
6. Перейди во вкладку **Стройка и расчёт**, выбери гекс, постройку, уровень, получи смету и план. При следующем полном снимке калькулятор сверит выполненные этапы.

Если калькулятор уже запущен старым Snippet, сначала закрой/перезагрузи вкладку: одновременно старую и новую версию запускать не нужно.

## Защита данных и ограничения

- Разрешены только `https://scouts.su/*` и локальное расширение Chrome `storage`.
- Перехватчик читает входящие JSON-сообщения **только** с типом `planetaryBase`, а затем передаёт только список гексов, здания, склад, энергию и идентификатор планеты. Токены, cookie, чат и полные WebSocket-пакеты не сохраняются.
- Последний очищенный снимок сохраняется локально через `chrome.storage.local` и отдаётся калькулятору по запросу. Проекты калькулятора хранятся в локальном хранилище сайта. **На GitHub и внешние серверы данные игрока не отправляются.**
- Никакие строительные, боевые, торговые и другие действия в игру не отправляются. Калькулятор не выполняет автоматическую стройку.
- Если игра передаёт только отдельные события `planetaryBase/cellUpdate`, но не полный `planetaryBase`, отслеживание остаётся на последнем полном снимке. Открой планету для нового полного сообщения. Автоматического опроса игрового сервера нет.
- Перехват `WebSocket` посредством Proxy может конфликтовать с будущими обновлениями игры; безопасность блокировок со стороны администрации не гарантируется, проверь правила SCOUTS. При проблемах отключи расширение и перезагрузи страницу.
- Это распакованное расширение. При обновлении файлов из GitHub требуется обновить локальную папку и нажать **Обновить** в `chrome://extensions` (или перезапустить Chrome). Обход ограничений Chrome MV3 удалённой загрузкой исполняемого кода не используется.

## Проверки

- `node --check scouts/SCOUTS_Calculator_v6.js`
- `node scouts/tests/test_capture.cjs`
- `node scouts/tests/test_bundle.cjs`

Браузерную интеграцию с реальным сервером SCOUTS необходимо проверить отдельно: локальные тесты используют имитацию сообщения `planetaryBase`.
