# SCOUTS Planet

Два рабочих режима: **Загрузка и отслеживание** и **Стройка и расчёт**.
Старое многовкладочное окно больше не запускается расширением.

- [Обновление и установка Chrome-расширения](scouts/README_EXTENSION.md)
- [Код нового интерфейса](scouts/SCOUTS_Planet_Workspace.js)
- [Небольшой загрузчик DevTools (запасной вариант)](scouts/loader-snippet.js)

Ветка `scouts-live`, `main` не изменена. Расширение использует локальные
скрипты, а не удалённое выполнение JavaScript из GitHub. Для обновления
распакованной версии заменяй файлы установленного расширения и обновляй
его в `chrome://extensions`.
