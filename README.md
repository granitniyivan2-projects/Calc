# SCOUTS Calculator — live GitHub snippet

Рабочая ветка: `scouts-live`. В ней только исходник SCOUTS, загрузчик и эта инструкция.
Старый проект `Calculator/` удалён **из рабочей ветки**, но сохранён в истории Git и в `main`.

## Установка один раз

1. Открой игру SCOUTS в Chrome и нажми `F12`.
2. `Sources → Snippets → New snippet` (назови `SCOUTS Live`).
3. Вставь содержимое файла [scouts/loader-snippet.js](scouts/loader-snippet.js), сохрани `Ctrl+S`.
4. Запускай этот короткий сниппет каждый раз, когда нужна панель: `Ctrl+Enter` при открытом сниппете, либо `Run`.

Загрузчик при каждом запуске получает последнюю версию из `scouts-live` на GitHub;
не нужно вручную заменять 150 КБ исходника в DevTools. Перезапуск в открытой вкладке
пересоздаёт панель; настройки калькулятора сохраняются локально в браузере.

## Файлы

- `scouts/SCOUTS_Calculator_v6.js` — полный калькулятор + симулятор планеты.
- `scouts/loader-snippet.js` — постоянный короткий загрузчик для Chrome DevTools.

## Обновление

Изменения коммитятся в ветку `scouts-live`; следующий запуск сниппета использует
обновлённый код. Встроены загрузка напрямую из GitHub без кеша и запасной путь
через jsDelivr. Запасной CDN иногда может отдавать кешированную версию.

## Важное

- Репозиторий **публичный**. Не добавляй сюда токены игры, API-ключи, куки,
  HAR-файлы, личные данные, снимки игры с идентификаторами сессий.
- Запускай сниппет только на доверенной странице и из доверенного репозитория.
- Строгая Content Security Policy страницы SCOUTS может заблокировать оба метода;
  работа в реальном браузере пока не подтверждена.
- Код не должен выполнять строительство на сервере: симулятор рассчитывает
  действия локально; перед использованием проверяй изменения механики игры.
