# SCOUTS Calculator · установка расширения

**Для автоматического получения снимков планеты без DevTools** используй
[инструкцию по установке Chrome-расширения](scouts/README_EXTENSION.md).

- Один раз установи папку `scouts` как распакованное расширение Chrome.
- Оно автоматически запускает калькулятор на `https://scouts.su/`.
- Полные события `planetaryBase` из игрового WebSocket передаются в окно
  «Планетарная база» и сверяют строительный план с текущим состоянием.
- Короткий [GitHub-сниппет](scouts/loader-snippet.js) остаётся запасным способом
  ручного запуска без расширения.
- Все изменения выполняются в ветке `scouts-live`, основная `main` не изменяется.

## Ограничения

Автоматический захват работает **только когда игра присылает полный `planetaryBase`**,
без дополнительных запросов к игровому серверу. При изменениях только
`cellUpdate` требуется открыть/обновить планету в игре. Последний очищенный снимок
сохраняется в локальном хранилище Chrome.

Расширение установлено локально (unpacked): новые коммиты GitHub сами по себе не
попадают в установленную папку. Для обновления нужна новая копия папки и
перезагрузка расширения в `chrome://extensions`. Публикация в Chrome Web Store
для автоматических обновлений не выполнялась.
