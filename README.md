# SCOUTS Calculator · Planet Workspace

**Рабочая ветка:** `scouts-live` (основная ветка `main` не изменяется).

## Запуск без скачивания

1. Открой страницу игры SCOUTS и в Chrome зайди в `F12 → Sources → Snippets`.
2. Создай один сниппет и вставь в него содержимое [scouts/loader-snippet.js](scouts/loader-snippet.js).
3. Запускай сниппет повторно через `Ctrl+Enter`, чтобы получить свежий код из GitHub.

При запуске автоматически открывается окно **Планетарная база**. Закрытие окна возвращает старые инструменты калькулятора, которые сохранены для совместимости.

## Два режима

**1. Загрузка и отслеживание**
- В игре открой Хранилища → Планетарные базы, выбери планету и обнови её.
- В `DevTools → Network → WebSocket → Messages` скопируй входящее событие `planetaryBase` целиком.
- В окне калькулятора нажми **Обновить снимок** и вставь JSON.
- Отобразятся настоящие координаты гексов, здания, запасы, энергетика и производственный поток.
- При повторном импорте одного объекта базы программа сравнивает изменение ресурсов и построек, сохраняет до 30 сводок изменений и отмечает выполненные шаги проекта.

**2. Стройка и расчёт**
- Выбери гекс на карте, тип здания и целевой уровень.
- Виртуальная очередь включает фундамент (если требуется), постройку, улучшения и выбранный рецепт.
- Каждому пункту соответствует действие и стоимость; порядок можно менять или оптимизировать.
- Смета показывает нужные ресурсы, текущие запасы и дефицит.
- Опция **Разложить дефицит до первичных ресурсов** рассчитывает сырьё и циклы изготовления промежуточных материалов по базовым рецептам.
- Переключатель «Сейчас / После стройки» сравнивает реальную карту и виртуальный проект.

## Геометрия

Квадратная генерация, редактирование ландшафта и произвольное изменение размера **убраны**.
Координаты поступают только из реального `planetaryBase`. Количество гексов фиксируется по первому загруженному полному снимку и проверяется при последующих импортах. Точное эталонное число гексов пока не подтверждено отдельным игровым образцом; тестовые фикстуры НЕ являются эталоном.

## Ограничения

- **Отслеживание по повторно загруженным снимкам**, без постоянного подключения к WebSocket. Автоматический захват данных ещё не реализован.
- Все строительные команды виртуальные; в игру ничего не отправляется.
- Разложение до первички — нормативный расчёт по каталогу, не симуляция доступных производственных мощностей, времени или приоритетов потребления.
- Старые локальные искусственные карты не используются как реальные: перед миграцией они резервируются в `localStorage` под ключом `scouts.planet.simulator.v1.legacy`.
- При следующем реальном снимке завершённые действия проекта автоматически снимаются из очереди; это эвристика, а не подтверждение выполнения команд.
- Репозиторий публичный. Не добавляй сюда токены, cookies, HAR с сессиями или другие секреты.

## Проверки

Синтаксис: `node --check scouts/SCOUTS_Calculator_v6.js`.

Браузерный тест: `python scouts/tests/test_planet_ui.py` (нужны Python Playwright и Chromium). Проверяет два режима, реальную сетку из JSON, смету/первичку, защиту от неполного снимка и закрытие выполненных шагов при обновлении.

Сохранённый в GitHub [загрузчик](scouts/loader-snippet.js) получает актуальный JavaScript из этой ветки при каждом запуске, без ручного копирования основного кода.
